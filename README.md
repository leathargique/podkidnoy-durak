# Подкидной дурак — игровая модель

Учебный проект (ВГУ, ФКН, Java). Вариант 1: подкидной дурак, этап 2 - механика. Проект не содержит пользовательского интерфейса и самостоятельной точки входа: игровое состояние создаётся и управляется через классы модели.

## Модель

- `Game` хранит состояние партии, проверяет ходы и возвращает события. Для создания партии укажите число игроков от 2 до 5 и зерно генератора случайных чисел: `new Game(2, 42)`. При одинаковых числе игроков и зерне начальная раздача будет одинаковой.
- `Player` содержит номер и руку игрока; `Card` — масть и достоинство. Колода состоит из 36 карт: от шестёрок до тузов четырёх мастей.
- `Deck` тасуется при создании партии. Нижняя карта задаёт козырную масть; первым атакует владелец младшего козыря, а если козырей на руках нет — игрок 0.
- `TablePair` представляет атакующую карту и карту, которой её отбили. `GameEvent` и `EventType` описывают ход партии; события хода возвращаются из методов и также доступны через `getEventLog()`.
- `IllegalMoveException` выбрасывается, если ход нарушает правила.

Состояние и доступные ходы можно проверять через геттеры `Game`, `canAttack`, `canDefend`, `getAttackCandidates` и `getDefenseCandidates`. Получаемые списки состояния предназначены только для чтения; менять руки игроков напрямую нельзя.

## Основные правила

1. В начале партии каждому игроку раздают по 6 карт. Игроки ходят по кругу.
2. Атакующий выкладывает карту. Защитник бьёт её старшей картой той же масти или любой козырной картой; козырь можно побить только старшим козырем.
3. Другие игроки, кроме защитника, могут подкидывать карты достоинства, уже присутствующего на столе. Всего за ход можно выложить не более 6 атакующих карт и не больше числа карт у защитника в начале хода.
4. Защитник может взять карты, пока на столе есть неотбитые. После объявления о взятии отбиваться уже нельзя, но подкидывание в пределах лимита продолжается до завершения хода.
5. Завершите ход вызовом `finishTurn()`: если защитник взял, он забирает карты со стола; если отбил все карты — они уходят в отбой. Затем игроки добирают до 6 карт, пока колода не пуста. Защитник добирает последним и не добирает, если взял карты.
6. После взятия атакующий начинает следующий ход. После успешной защиты атакующим становится прежний защитник. Когда колода пуста и у всех, кроме максимум одного игрока, закончились карты, партия завершается. Последний игрок с картами — проигравший; `getLoser()` возвращает `-1`, если партия ещё не закончена или завершилась без проигравшего.

## Сборка и тесты

Нужны JDK 25 (проект компилируется с `--release 25`) и Maven.

```bash
mvn test
```

Для полной сборки:

```bash
mvn package
```

Интерактивно запустить игру нельзя: в проекте нет `main`-класса. Чтобы использовать механику, создайте `Game` в своём приложении и вызывайте методы ходов (`attack`, `defend`, `take`, `finishTurn`).
